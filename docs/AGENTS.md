## 目录结构

- `_logs`：日志文档
  所有的文件以 `YYYY-MM-DD {topic}` 格式命名。
- `book`：使用指南文档（非目前焦点，低优先级）
- `designs`：设计文档
  永远不得出现沿革性质的描述，只描述当前最新设计状态，并禁止不必要的引用，确保内容准确、信息密度高、简明、易于阅读，在修改时要保证不存在重复或矛盾的问题。
- `thoughts.not`：一些想法积累
- `draft.not`：临时性的草稿
- `todos.not`：一些已确定需要完成的任务

## notist 属性

在本目录下，Notist 的一些属性标注含义约定如下：

| 属性 | 类型 | 含义 |
|------|------|------|
| `draft` | bool | 草稿内容 |
| `ai` | bool | 是否是由 AI 直接生成的内容 |
| `desc` | string | 简单描述/摘要 |
| `agents` | string | 对该 Node 生效的类 AGENTS.md 的提示，在操作对应 Node 前必须确保阅读并理解 |

在生成文档时，如果对应部分内容完全由 AI 生成，则必须标注上 `ai: true` 属性。
