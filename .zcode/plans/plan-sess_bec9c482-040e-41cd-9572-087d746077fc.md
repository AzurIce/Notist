# 将 `inspect outline` 改造为 `inspect items`：模块内可寻址 Item 表

## 语义

按 D0004（designs/world/reference-ref-target.not），Item = 模块内可寻址实体，ItemName 是模块内扁平唯一命名空间。新命令 `notist inspect items <MODULE|PATH>` 一次列出模块内全部 Item，取代 heading 嵌套树视图（嵌套信息保留为 level 列）：

- **scope Item**：显式 `@id` 标注的节点（含非 heading 节点）+ heading 默认名（标题文本）；`@id` 覆盖所在 heading 的默认名；重名 heading 标注 `ambiguous`（无法用名字单独寻址）。
- **resource Item**：模块目录下的资源文件（image/file），无源内 range，location 指向资源文件本身。
- 每个 Item 附带**它承载的属性注解**（注解表条目完整落入 Item range 者——即上一轮审查中"outline 应带属性"建议的落地形态）。
- `let` 绑定不是 Item（D0004 词法世界，明确排除），不进表。
- `--depth` 随 outline 一起移除（扁平表没有深度）。

## 实施步骤

### 1. service 查询层 `crates/notist-service/src/query.rs`

- 删 `OutlineQuery`/`OutlineHeading`/`default_outline_depth`/`outline()`。
- 新增 `ItemsQuery { selector: Selector }`（selector 带名字时报 `invalid_argument`）与 `ItemRecord { name, kind, origin, level, ambiguous, location, attributes }`：
  - `kind`: `"scope" | "resource:image" | "resource:file"`；`origin`: `"id" | "heading" | "resource"`。
- 新增 `pub fn items(workspace, snapshot, query)`，全部复用现成公开接口：
  1. `resolve_source`（无 name）；
  2. `workspace.module_heading_default_ids(path)` → 权威 (name, range) 列表（与 `resolve_item_name` 解析一致）；
  3. `workspace.labels()` 按 module 过滤：scope_range 包含某 default range 的 label 覆盖该行（origin=id），未覆盖任何 heading 的 label 自成一行（range=scope_range）；
  4. default 名在覆盖处理后仍重名 → 两行 `ambiguous: true`；
  5. `workspace.module(path).resources` → resource 行（location 用资源文件自身相对路径，byte_range 0..0）；
  6. `workspace.structured_module(module.id)` 注解表 → 每行认领完整落入自身 range 的条目（复用 `fully_contains` + `attribute_records`）；
  7. level 从 `structured.tree` 走一遍 heading（range.start → level）匹配；排序按 range.start，resource 行殿后。

### 2. 请求面 `crates/notist-service/src/request.rs`

- 删 `CoreRequest::OutlineModule`/`OutlinePage` 派发对；**顺带清理无发送方的死协议面** `CoreRequest::Outline`/`CoreResponse::Outline`/`OutlineRecord`（探索已确认 workspace 内无任何 sender）。
- 新增 `CoreRequest::Items { view_id, query: ItemsQuery }`、`CoreResponse::Items(QueryResult<ItemRecord>)`、`view_id()` 臂、派发臂（仿 OutlineModule 模式）。

### 3. CLI `crates/notist-cli/src/main.rs`

- `InspectCommand::Outline { selector, depth }` → `Items { selector }`（doc comment 更新；line 24 long-about 与 line 60 Inspect about 的命令列举同步）。
- handler：一行一 Item，格式 `name  kind [L{level}]  path:line  @[attrs]`，ambiguous 行尾加 ` (ambiguous)`；资源行 `name  resource:image  assets/...`。
